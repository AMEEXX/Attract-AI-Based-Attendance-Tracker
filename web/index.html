Core Architecture

Engineered to Fail-Closed and Protect Privacy

⚡

Face ID Hands-Free Auto-Capture

No tedious taps per angle. Turn your head smoothly (Straight → Left → Right); the calibrated relative nose-offset engine captures each pose seamlessly in real time.

🔒

100% Offline & Zero Cloud

No external network calls, no telemetry, no cloud biometric databases. Facial images are processed in-memory and immediately discarded; only encrypted vectors persist.

🛡️

Self-Service Enrollment (D-007)

Students select and confirm their own names directly from the roster. No teacher PIN bottlenecks; atomic Room transactions link templates and mark present instantly.

🎯

Calibrated BGR Precision

Switched tensor input preprocessing from RGB to BGR order, unlocking MobileFaceNet's native accuracy: EER reduced from 2.11% to 1.55%, TAR @ 0.1% FAR up to 96.7%.

📱

Hardware Kiosk Lockdown

Teacher's phone enters Android Screen Pinning (Lock Task Mode) during attendance sessions. Students check in safely without access to personal apps or notifications.

🔄

Room v5 Clean Migration

Includes automated SQLite migration v4→v5 and an administrative "Reset All Face Data" failsafe in Settings that purges legacy corrupted templates while retaining roll history.
